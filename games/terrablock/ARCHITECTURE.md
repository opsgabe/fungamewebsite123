# Terrablock architecture

Terrablock is a Minecraft-style voxel sandbox for the browser, built with original art: every texture,
model, sound and name is generated by our own code. **Never copy Minecraft/Mojang assets, names of
its mobs, its logo or text.** Mechanics (mining, crafting, survival) are fine.

Plain ES modules, no bundler. three.js r186 is vendored at `vendor/three.module.min.js`; import it with
`import * as THREE from '../vendor/three.module.min.js';` from files in `src/`.
Shared constants live in `src/config.js` (already written; read it first and use it, don't duplicate).
The page is served statically (GitHub Pages) from `games/terrablock/index.html`.

## Files and owners

| `src/textures.js` | A | procedural 256x256 texture atlas, icons, crack tiles |
| `src/noise.js`, `src/worldgen.js` | B | seeded noise; terrain/biomes/caves/ores/trees; spawn finder |
| `src/mesher.js` | C | chunk -> geometry (culling, AO, skylight, cross plants, water) |
| `src/chunkworker.js`, `src/world.js`, `src/renderer.js`, `src/save.js` | D | workers, chunk streaming, edits, rendering, sky, persistence |
| `src/player.js`, `src/interaction.js`, `src/audio.js` | E | movement/physics, block targeting/break/place, procedural sound |
| `index.html`, `ui.css`, `src/ui.js`, `src/items.js`, `src/inventory.js`, `src/crafting.js`, `src/survival.js`, `src/furnace.js` | F | all DOM UI, items, inventory, recipes, health/hunger, furnaces |
| `src/mobs.js` | G | animals and night monsters |
| `src/main.js` | H (integration) | boot, game loop, wiring, saving cadence |

Modules must only depend on other modules through the interfaces below. Blocks.js, items.js,
noise.js, worldgen.js, mesher.js and config.js must not touch the DOM (they are imported by workers
or by Node tests).

## Coordinates and data

- World axes: +y up. Chunks are 16 x 128 x 16 columns. Chunk data is a `Uint8Array(CHUNK_VOLUME)` of
  block ids indexed by `blockIndex(lx, y, lz) = lx + lz*16 + y*256`.
- Chunk (cx, cz) covers world x in [cx*16, cx*16+15], z likewise. Use `toChunk`, `toLocal`.
- Block positions are integer corners: block (x,y,z) occupies [x,x+1] x [y,y+1] x [z,z+1].
- Player position is the centre of the feet.
- Time of day `t` in [0,1): 0 = sunrise, 0.25 = noon, 0.5 = sunset, 0.75 = midnight. Night = t in [0.52, 0.98).

## Atlas tiles (textures.js draws all of them; blocks.js references them)

- Tiles 0..175: block faces (A chooses the assignment; blocks.js `textures` must match textures.js).
- Tiles 176..185: block-breaking crack overlay stages 0..9 (transparent with dark cracks). Export `CRACK_TILES`.
- Tiles 192..255: item icons, `itemTile(id) = 192 + (id - 256)` for ids 256..279.
- Atlas canvas is 256x256 px (16x16 tiles of 16 px), drawn deterministically (seeded PRNG, not
  Math.random) in an original pixel-art style. UVs via `tileUV(tile)` from config.js.

## Module contracts

### blocks.js (A)
```js
export const B = { AIR: 0, STONE: 1, ... };               // table above
export const BLOCKS = [];                                    // BLOCKS[id] = def, undefined for unused ids
export function getBlock(id)                                 // def or BLOCKS[0]
export function isSolid(id), isOpaque(id)                    // fast lookups (precomputed Uint8Arrays ok)
// def fields:
{ id, name,                       // display name, e.g. 'Stone'
  solid,                          // collides with player/mobs
  opaque,                         // full opaque cube: hides neighbour faces, contributes to AO and skylight
  renderLayer,                    // 'opaque' | 'cutout' (leaves, glass, plants, cactus) | 'water' | 'none'
  shape,                          // 'cube' | 'cross' | 'none'
  textures: { top, bottom, side, front? },  // atlas tile indices; `front` (crafting table, furnace, pumpkin) is used on the +z face
  hardness,                       // seconds-ish like the original (dirt 0.5, stone 1.5, log 2, ores 3, obsidian 50); -1 = unbreakable
  tool,                           // 'pickaxe' | 'axe' | 'shovel' | null (preferred tool)
  minTier,                        // null, or the pickaxe tier required for a drop (stone/cobble 0, iron ore 1, gold/diamond ore 2, obsidian 3)
  drop, dropChance,               // item id dropped (default: own id; null = nothing), probability (default 1)
                                  // STONE->COBBLESTONE, GRASS/SNOWY_GRASS->DIRT, COAL_ORE->257, DIAMOND_ORE->260,
                                  // LEAVES/BIRCH_LEAVES/SPRUCE_LEAVES->277 APPLE with dropChance 0.05, GLASS/TALL_GRASS/ICE->null
  sound,                          // 'stone'|'wood'|'dirt'|'sand'|'gravel'|'grass'|'glass'|'leaves'|'snow'|'wool'
  liquid,                         // water only
  gravity,                        // sand, gravel fall when unsupported
  color }                         // average CSS colour (particles, debug)
```

### noise.js / worldgen.js (B) — pure, worker-safe
```js
export function hashSeed(str)                    // string -> 32-bit int (numeric strings parse as numbers)
export function generateChunk(cx, cz, seed)      // -> Uint8Array(CHUNK_VOLUME); deterministic; < 15 ms typical
export function findSpawn(seed)                  // -> {x, y, z}: feet position on dry, solid land near (0,0), with 2 air blocks above
export function biomeAt(x, z, seed)              // -> 'ocean'|'beach'|'plains'|'forest'|'birch_forest'|'desert'|'snowy'|'taiga'|'mountains'
```
Features: smooth continental + hill + mountain noise heightmap; biomes from temperature/humidity noise with
smooth transitions; beaches and oceans at SEA_LEVEL (ICE on top of water in snowy biomes); grass/dirt
(3-4 dirt), sand/sandstone in deserts and beaches, snowy grass + spruce in cold biomes, stone mountains with
snow caps; 3D-noise caves and ravine-like worms that rarely breach the ocean floor; ores by depth
(coal common < y 100, iron < 64, gold < 32, diamond < 16); bedrock floor y=0 plus random y 1..3; gravel/clay
patches; trees (oak, birch, spruce; cacti and dead bushes in desert; tall grass and flowers in plains) placed
deterministically from world coordinates so trees crossing chunk borders are complete in both chunks;
occasional pumpkins/melons. Water fills air at y <= SEA_LEVEL only where connected to oceans/lakes by the
heightmap (no water inside caves above sea-level terrain).

### mesher.js (C) — pure, worker-safe
```js
export function buildChunkMesh(cx, cz, getChunk) // getChunk(dx, dz) for dx,dz in {-1,0,1} -> Uint8Array | null (null => treat as AIR)
// -> { opaque: Geo, cutout: Geo, water: Geo }
// Geo = { positions: Float32Array (chunk-local xyz), uvs: Float32Array, colors: Float32Array (rgb), indices: Uint32Array }
```
Rules: draw a cube face when the neighbour is not opaque and is not the same id for cutout/water blocks.
Vertex colour (grey, r=g=b) = faceShade x AO x skyLight. faceShade: top 1.0, bottom 0.5, +/-x 0.8, +/-z 0.65.
AO: classic 3-sample voxel AO (side1, side2, corner) -> [0.55, 0.7, 0.85, 1.0]; flip quad diagonal when
needed to avoid anisotropy. skyLight: per column topmost opaque y (heightmap over the 3x3 chunk area);
a cell above its column's top is 1.0, below it 0.3 (cave darkness); vertex value = average of the 4 cells
touching the vertex on the face's open side. Cross plants: two diagonal quads (cutout layer, rendered
double-sided). Water: top surface at y+0.875 when the block above is not water; faces against air or
non-opaque non-water. Cactus: inset 1/16 on sides. UVs from `tileUV`, oriented so textures are upright on sides.

### chunkworker.js, world.js, renderer.js, save.js (D)
```js
// renderer.js
export class Renderer {
  constructor({ canvas, atlasCanvas })   // WebGLRenderer, scene, camera (PerspectiveCamera 70, near 0.1, far 1000)
  scene; camera; atlasTexture;           // CanvasTexture: NearestFilter, no mipmaps, SRGBColorSpace
  materials: { opaque, cutout, water }   // MeshBasicMaterial with map + vertexColors; cutout alphaTest 0.5 DoubleSide; water transparent
  setTimeOfDay(t)                        // sky gradient, fog, sun/moon, stars, clouds; scales material colours by daylight (min 0.18)
  setRenderDistance(chunks)              // fog distance
  setUnderwater(bool)                    // dense blue fog
  setFov(deg); resize(); render();
  get daylight()                         // 0..1
}
// world.js
export class World {
  constructor({ seed, renderer, renderDistance, edits })   // edits: { "cx,cz": { index: id } } from save
  async init(x, z, onProgress)          // resolves once chunks within radius 2 of (x,z) are generated and meshed
  update(playerPos)                      // stream nearest-first via a worker pool, unload far chunks (dispose geometries)
  getBlock(x, y, z)                      // id; 0 above WORLD_HEIGHT, BEDROCK below 0, -1 if chunk not loaded
  setBlock(x, y, z, id)                  // -> bool; records edit; remeshes synchronously on the main thread (+ border neighbours);
                                         // sand/gravel above an emptied cell fall to the first non-air cell below
  isSolid(x, y, z)                       // unloaded counts as solid
  highestBlockAt(x, z)                   // y of topmost solid block, -1 if none / unloaded
  setRenderDistance(n); getEdits(); stats() -> { loaded, meshed, pending }; dispose();
}
// save.js (localStorage; every access wrapped in try/catch)
export function listWorlds()             // [{ id, name, seed, mode, lastPlayed }], newest first
export function createWorld({ name, seed, mode }) // -> meta with id
export function loadWorld(id)            // -> { meta, player, inventory, survival, time, edits, furnaces } | null
export function saveWorld(id, data)      // -> bool (false on quota errors)
export function deleteWorld(id)
export function loadSettings(); export function saveSettings(s)   // { renderDistance, fov, sensitivity, invertY, volume }
```
Worker pool: `new Worker(new URL('./chunkworker.js', import.meta.url), { type: 'module' })`, size
clamp(hardwareConcurrency - 1, 1, 4). Generation and meshing both run in workers; edited chunks remesh on the
main thread via the same `buildChunkMesh` for instant feedback. Only mesh a chunk once its 4 side neighbours
have data. Remesh border neighbours when a chunk's data arrives.

### player.js, interaction.js, audio.js (E)
```js
export class Player {
  constructor({ world, camera, domElement, settings, sounds })
  position; velocity; yaw; pitch; mode; flying; sneaking; sprinting; onGround; enabled;
  setMode(mode); teleport(x, y, z); update(dt);
  getEyePosition(); getLookDirection(); isInWater(); isHeadInWater(); getAABB();
  onFall = null;   // (distance) => {}  set by main; survival fall damage = max(0, ceil(distance - 3))
  toJSON(); fromJSON(obj);
}
```
Controls: WASD move, mouse look (pointer lock on `domElement`), Space jump / swim up / fly up, double-tap Space
toggles flying in creative, Shift sneak (no falling off edges) / fly down, Ctrl or double-tap W sprint.
AABB 0.6 x 1.8 swept collision per axis with step-free movement; unloaded chunks are solid. Water: slow
movement, buoyant swim. Camera at eye height with slight FOV boost when sprinting.
```js
export class Interaction {
  constructor({ world, player, renderer, inventory, survival, mobs, sounds, getMode, callbacks })
  // callbacks: { onUseBlock(x, y, z, id) -> bool, onBlockBroken(x, y, z, id) }
  enabled; target;  // { x, y, z, id, normal: [nx,ny,nz] } | null
  update(dt);
}
```
Voxel DDA raycast (reach from config). Highlight box outline on the target. Left button: hit a mob first via
`mobs.attack(origin, dir, reach, damage)`; otherwise break. Creative: instant break, repeat every 0.25 s while
held. Survival: hold to break; time = hardness x 1.5 / toolSpeed with the right tool, hardness x 5 when
`minTier` isn't met (and no drop); crack overlay mesh using CRACK_TILES; drops go straight into the inventory
(`inventory.add`). Right button: use crafting table / furnace (`onUseBlock`), else eat held food in survival
when hungry, else place the held block on the targeted face (not inside the player, cross plants only on
grass/dirt, replaces water/tall grass). Middle button: creative pick-block. Sounds via `sounds.play`.
```js
export class Sounds { constructor(); unlock(); setVolume(v); play(name, { material, volume, pitch } = {}) }
// names: 'dig','break','place','step','hurt','splash','eat','pop','click','mobHurt','mobDeath' — procedural WebAudio
```

### mobs.js (G)
```js
export class MobManager {
  constructor({ world, renderer, player, survival, inventory, sounds, getMode })
  update(dt, { timeOfDay, isNight });
  attack(origin, dir, reach, damage) -> bool;   // ray vs mob AABBs; knockback; drops into inventory on death

```
Original mob designs built from box meshes with procedural canvas textures: two passive animals that
wander on grass in daylight (one drops RAW_MEAT, one drops WOOL_WHITE) and two night/underground monsters
in survival (a slow melee walker and a fast leaping crawler). Same AABB-vs-voxel collision as the player,
1-block step via jump, fall with gravity, hurt flash, death animation, despawn far away (> 64 blocks) and
monsters at sunrise. Caps: 10 passive, 8 hostile. Monsters do not attack in creative.

### main.js (H)
Boot: load settings, create Renderer/Sounds/UI, show title. Create/play world: load save, World.init with a
loading screen, place player (saved position or `findSpawn`), creative starter hotbar, start the loop.
Loop: clamp dt to 0.05, update player, interaction, mobs, furnaces, survival, world streaming, time of day,
renderer; HUD refresh; autosave every 30 s and on `pagehide`/save & quit. Pointer lock: click canvas to lock;
unlocking opens the pause menu unless a UI screen is open. Death -> death screen -> respawn at spawn with an
empty inventory (survival).
